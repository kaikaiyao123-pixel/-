## 命名规则

后续新增对话建议使用以下格式：

```text
项目名称｜工作阶段或主题
```

推荐阶段名称：

- 需求分析
- 方案设计
- 主功能实现
- 评审修复
- 测试验收
- 发布整理

## 后续维护建议

1. 同一项目的需求、实现、评审和验收记录统一放在对应项目下。
2. 新开对话时直接使用“项目｜阶段”作为标题，避免使用自动生成的长句标题。
3. 只有完全重复、空白或明显无后续价值的记录才归档。
4. 归档前保留至少一条主实现记录和一条验收记录，确保项目过程可追溯。
5. 每完成一个阶段，可将最终结论补充到项目 README 或计划文档中，减少对历史对话的依赖。
